# Доменные сущности

Основание: `Docs/TechnicalTask.md`.

## 1. Общие сквозные сущности
| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Организация | ООО «Ромашка» — юридическое лицо, владеющее сетью ресторанов и производственным цехом | — |
| Ресторан | Одна из 10 точек сети, работает с 10:00 до 22:00. Хранит адрес, координаты (широта и долгота) и формат работы: только доставка, комбинированный или только зал. Координаты нужны, чтобы выбрать ближайший ресторан для заказа на доставку (п. 3.2). Заказы на доставку получают рестораны с доставкой | → Организация (N–1); → Район доставки (N–N, обслуживаемые районы) |
| Производственный цех | Отдельное подразделение, работает круглосуточно, готовит заготовки и хранит централизованно закупаемые мясные и молочные продукты | → Организация (N–1) |
| Помещение | Физическое пространство, в котором расположен склад: помещение ресторана, цеха, холодильник цеха (п. 1.2). У ресторана или цеха может быть несколько помещений | → Ресторан или Производственный цех (N–1, владелец) |

## 2. Складской учет
| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Номенклатура | Единица учета: сырье, товар, полуфабрикат, блюдо, упаковка (п. 1.1). Хранит тип позиции и единицу измерения. Удаление блокируется, если позиция участвует в складском учете (п. 6.2) | → Группа номенклатуры (N–1) |
| Группа номенклатуры | Классификатор номенклатуры (п. 1.1). Удаление блокируется, если номенклатура группы участвует в складском учете (п. 6.2) | — |
| Склад | Место хранения остатков (п. 1.2). Чей склад, определяется через помещение | → Помещение (N–1) |
| Остаток | Количество номенклатуры на конкретном складе. Хранится отдельно и меняется одновременно с записью в журнале складских операций, а не вычисляется из него. Пара «склад + номенклатура» уникальна. При списании «под сальдо» может быть отрицательным (п. 2.4) | → Склад (N–1); → Номенклатура (N–1) |
| Журнал складских операций | Запись о каждом движении номенклатуры по складу: приход или расход, количество, дата, ответственный (п. 5.3). Записи создаются документами (приготовление, выпуск, списание номенклатуры, инвентаризация), изменять и удалять их нельзя | → Склад (N–1); → Номенклатура (N–1); → Сотрудник (N–1) |
| Инвентаризация | Документ пересчета остатков склада. Плановая: ежемесячно по всей номенклатуре (п. 1.3); частичная: несколько раз в месяц по одной группе (п. 1.4). Содержит позиции: номенклатура, учетное и фактическое количество | → Склад (N–1); → Группа номенклатуры (N–1, необязательная: заполнена только у частичной) |

## 3. Производственный учет
| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Технологическая карта | Рецепт получения полуфабриката или блюда (п. 2.1). Состав: номенклатура-сырье с количеством или другая технологическая карта (п. 2.5), нужна защита от циклов | → Номенклатура (N–1, результат); → Номенклатура (N–N, состав); → Технологическая карта (N–N, вложенные карты) |
| Приготовление полуфабриката | Документ: сырье списывается по карте, полуфабрикат оприходуется. Порождает документ списания номенклатуры | → Технологическая карта (N–1); → Склад (N–1); → Заказ на производство (N–1, необязательная) |
| Приготовление блюда | Документ: полуфабрикаты и сырье списываются по карте, блюдо оприходуется. Порождает документ списания номенклатуры | → Технологическая карта (N–1); → Склад (N–1); → Заказ на производство (N–1, необязательная) |
| Выпуск продукции | Документ выпуска готовой продукции, например заготовок из цеха в рестораны. Увеличивает остатки. Содержит позиции: номенклатура, количество | → Склад (N–1); → Заказ на пополнение склада (N–1, необязательная) |
| Утилизация продукции | Документ списания испорченной или просроченной продукции. Порождает документ списания номенклатуры. Содержит позиции: номенклатура, количество | → Склад (N–1) |
| Списание номенклатуры | Документ уменьшения остатков. Хранит режим списания: «с блокировкой» — запрет при недостатке остатка (п. 2.3) или «под сальдо» — без блокировки, остаток может уйти в минус (п. 2.4). Содержит позиции: номенклатура, количество. Проведение создает расходные записи в журнале складских операций. Не путать со списанием денежных средств из раздела 5 | → Склад (N–1); → Приготовление полуфабриката, Приготовление блюда или Утилизация продукции (N–1, документ-источник) |

## 4. Курьерская служба
| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Район доставки | Строго определенная зона доставки. Хранит название и стоимость доставки (п. 3.1) | — |
| Меню доставки | Отдельное меню для доставки, у каждого ресторана свое. Содержит блюда с ценой, в каждое включена упаковка (п. 3.3) | → Ресторан (N–1); → Номенклатура (N–N, блюда и упаковка) |
| Заказ на доставку | Заказ клиента. Хранит адрес клиента, координаты адреса и итоговую стоимость: позиции плюс доставка в район (п. 3.1). Назначается ближайшему ресторану с доставкой по координатам (п. 3.2). Содержит позиции из меню выбранного ресторана. Относится к оперативному учету (п. 6.1) | → Ресторан (N–1); → Район доставки (N–1) |

## 5. Финансовый учет
| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Контрагент | Юридическое лицо, в разрезе которого ведется учет денежных средств (п. 4.1) | → Группа контрагентов (N–1) |
| Группа контрагентов | Классификатор контрагентов (п. 4.1) | — |
| Тип оплаты | Способ оплаты: наличные, банковский перевод и прочее (п. 4.2) | — |
| Поступление | Документ прихода денежных средств (п. 4.3). Хранит сумму и дату | → Контрагент (N–1); → Тип оплаты (N–1) |
| Списание денежных средств | Документ расхода денежных средств (п. 4.3). Хранит сумму и дату. Не путать со списанием номенклатуры из раздела 3 | → Контрагент (N–1); → Тип оплаты (N–1) |

## 6. Учет персонала
| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Сотрудник | Карточка сотрудника. Удаление блокируется, если он участвовал в складском, оперативном или финансовом учете (п. 6.3) | → Категория сотрудников (N–1); → График работы (N–1); → Ресторан или Производственный цех (N–1, место работы) |
| Категория сотрудников | Производство, обслуживание, управление. Определяет вид графика: производство работает посменно (сменный график), остальные по 8 часов в день кроме выходных и праздников (стандартный график) | — |
| График работы | Правило рабочего времени (п. 5.1): сменный (смена до 8 часов, индивидуальный) или стандартный (8 часов в день, кроме выходных и праздников). Хранит тариф; время сверх графика оплачивается по двойному тарифу (п. 5.2). Вид графика должен соответствовать категории сотрудника | → Календарь выходных и праздников (N–1) |
| Календарь выходных и праздников | Набор выходных и праздничных дат, по которым не работают сотрудники со стандартным графиком. Отдельная сущность, чтобы в будущем загружать его как свой объект в график работы | — |
| Смена | Плановый интервал работы в рамках графика | → График работы (N–1) |
| Учет рабочего времени | Факт начала и завершения работы сотрудника. По сравнению с графиком определяется переработка (п. 5.2) | → Сотрудник (N–1) |

## 7. Оперативный учет
| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Заказ на доставку | Описан в разделе 4 | См. раздел 4 |
| Заказ на пополнение склада | Заявка ресторана в производственный цех на заготовки и централизованные продукты к началу рабочего дня. Содержит позиции: номенклатура, количество | → Ресторан (N–1, заказчик); → Производственный цех (N–1, исполнитель) |
| Заказ на производство | Заявка на изготовление продукции. Цех работает круглосуточно | → Технологическая карта (N–1); → Производственный цех (N–1) |

## Общие правила

- **Ответственный сотрудник.** Каждый документ (инвентаризация, производственные документы, выпуск, утилизация и списание номенклатуры, поступление и списание денежных средств, все заказы) хранит ссылку `→ Сотрудник (N–1)`, п. 5.3. В таблицах она не повторяется.
- **Защита от удаления.** Номенклатура, группа номенклатуры (п. 6.2) и сотрудник (п. 6.3) не удаляются, если на них есть ссылки из учета.
- **Режим списания.** Хранится только в документе «Списание номенклатуры». Документы приготовления и утилизация передают его при создании списания.
- **Базовый класс.** Все сущности наследуются от `BaseEntity` (`id`, `name`).
